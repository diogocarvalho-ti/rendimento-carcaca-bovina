# 🐂 Calculadora de Rendimento de Carcaça Bovina

Projeto desenvolvido em **Java** para calcular o rendimento de carcaça de bovinos com base no peso vivo do animal e no peso da carcaça após o abate.

## 📌 Objetivo

Aplicar conceitos básicos de programação em uma situação prática relacionada à pecuária.

O programa solicita:

* Peso vivo do animal, em kg
* Peso da carcaça, em kg

Em seguida, calcula automaticamente o percentual de rendimento de carcaça.

## 🧮 Fórmula utilizada

**Rendimento de carcaça (%) = (Peso da carcaça / Peso vivo) × 100**

### Exemplo

* Peso vivo: 520 kg
* Peso da carcaça: 286 kg
* Rendimento: 55%

## 💻 Tecnologias e conceitos utilizados

* Java
* Entrada de dados com `Scanner`
* Variáveis do tipo `double`
* Operações matemáticas
* Saída formatada com `printf`

## ▶️ Exemplo de funcionamento

```text
=== CALCULADORA DE RENDIMENTO DE CARCACA BOVINA ===

Digite o peso vivo do animal (kg): 520
Digite o peso da carcaca (kg): 286

=== RESULTADO ===
Peso vivo: 520.00 kg
Peso da carcaca: 286.00 kg
Rendimento de carcaca: 55.00%
```
